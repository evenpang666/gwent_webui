# 游玩与存档

[返回 README](../README.md)

## 基本操作

1. 选择北方领域、尼弗迦德、怪兽、松鼠党或史凯利杰，点击「开始对局」。
2. 开局抽 10 张牌，最多更换 2 张。用鼠标滚轮、触控板或左右方向键浏览卡片，点击中间卡牌更换；点击「保留手牌」结束换牌。
3. 点击手牌查看中文说明，再点击高亮位置打出。诱饵需先点击己方战斗排，再选择要收回的非英雄单位。
4. 点击领袖卡，在查看器中确认使用领袖能力，每场一次。
5. 点击「放弃本小局」后，本小局不再行动。双方放弃后比较总战力，失去两颗生命宝石即败。
6. 对局结束后可重赛、更换电脑对手，或回到牌桌调整卡组。

顶部音量滑块支持 0–100%，立即影响正在播放的音效；0% 静音，设置自动保存。

## 牌组与规则

点击「卡牌收藏」或「调整卡组」编辑牌组：左侧点击加入，右侧点击移出，领袖卡可切换。牌组至少 22 张单位牌、最多 10 张特殊牌，以及一张领袖；支持 JSON 导入导出。

本项目采用《巫师 3》内置小游戏规则，含《石之心》《血与酒》和次世代更新卡牌。独立游戏《巫师之昆特牌》的两排战场及逐局补牌规则不适用。

英雄免疫行加成和天气等影响。计分顺序为：天气 → 间谍领袖加成 → 同袍 → 士气 → 号角；同袍按同名数量相乘，号角不叠加。完整规则参考[官方手册](https://cdn-l-thewitcher.cdprojektred.com/media/TW3/Pdf/GwentManuals/en-Manual-Gwent-ONLINE.pdf)。

卡图中的原始文字为英文，中文名称与技能说明显示在卡牌详情中。界面以桌面牌桌为主，窄屏可横向滚动。

## 暂离与继续

- 点击「暂离并保存」暂停对局。若动画或技能还在结算，游戏会先完成当前动作再暂停。
- 暂离后可「返回继续游戏」，也可「返回首页，稍后再玩」。重新打开页面或重启服务后，点击首页的「继续上次对局」。
- 每个完整动作后的回合边界自动缓存。刷新或意外关闭时，恢复最近一次完整状态；未完成的动画或技能选择回到该动作之前。
- 换牌阶段保留手牌、剩余换牌次数和当前浏览位置。

## 存档范围

存档包括双方牌库顺序、手牌、战场、弃牌、天气、生命宝石、领袖状态和小局记录。读档不会重新执行抽牌、医生、间谍、召集或第三局复活。

数据保存在当前浏览器、当前站点地址的 `localStorage` 中，只保留一场进行中的对局。开始新对局会替换旧进度，整场结束后清除该进度。

更换浏览器、设备、协议、IP、域名或端口不会共享存档。例如 `127.0.0.1`、`localhost` 和局域网 IP 属于不同地址。清理浏览器站点数据会删除本地进度、牌组和音效设置。
