# 部署与网络

[返回 README](../README.md)

## 环境

需要 Node.js 18 或更新版本及浏览器。项目没有第三方 npm 依赖，不需要安装依赖或构建。卡图、脚本和音效随项目保存，下载完整目录后可离线游玩。

确认环境：

```sh
node -v
npm -v
```

## 启动方式

在项目目录执行 `npm start` 或 `node server.cjs`，手动打开 `http://127.0.0.1:5173`。

| 系统 | 自动打开浏览器 |
| --- | --- |
| Windows | 双击项目根目录的 `启动游戏.cmd` |
| Linux / macOS | 在项目目录执行 `sh start.sh` |

`start.sh` 会检查 Node.js 版本。Linux 使用 `xdg-open`，macOS 使用 `open`；无桌面环境或自动打开失败时，手动访问终端显示的地址即可。也可执行 `chmod +x start.sh`，以后用 `./start.sh` 启动。

关闭服务终端或按 `Ctrl+C` 停止。下次启动后，使用相同浏览器和地址恢复本地进度。

直接打开 `index.html` 也可游玩，但建议使用上述服务器，以保证存储、音频和局域网地址提示正常工作。

## 局域网访问

1. 在电脑启动服务，保持电脑和服务运行。
2. 手机或其他设备连接同一路由器。
3. 在设备浏览器打开页面底部小字或启动终端显示的 URL，例如 `http://192.168.1.100:5173`。

服务器默认监听 `0.0.0.0:5173`，浏览器中应填写电脑的实际 IP。地址自动读取电脑网卡，优先选择名称可识别的以太网 IPv4，过滤 VMware、Hyper-V、VPN 等常见虚拟接口；没有以太网时回退到 Wi-Fi。重新联网或返回标签页时更新提示。

手机建议横屏；窄屏保留完整牌桌，可横向滚动。每台设备独立对战电脑，对局、牌组和音效设置保存在各自浏览器中，不跨设备同步。

若无法访问，参见[局域网排障](troubleshooting.md#手机或其他设备打不开)。服务不会自动修改系统防火墙或路由器配置。

## 更换端口

Windows PowerShell：

```powershell
$env:PORT = "8080"
npm start
```

Windows 命令提示符：

```bat
set PORT=8080
npm start
```

Linux / macOS：

```sh
PORT=8080 npm start
```

然后访问 `http://127.0.0.1:8080`，局域网提示也会使用新端口。更换端口会切换浏览器存储空间；旧进度仍需通过原端口读取。
