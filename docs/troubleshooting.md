# 详细排障

[返回 README](../README.md)

## 找不到 node 或 npm

安装 Node.js 18 或更新版本，重新打开终端，执行 `node -v`、`npm -v`。若仍提示找不到命令，检查 Node.js 安装目录是否加入系统 `PATH`。

## 页面打不开或端口被占用

- 确认在项目目录运行了 `npm start`，终端没有报错，并保持服务运行。
- 在电脑本机打开 `http://127.0.0.1:5173`，不要把监听地址 `0.0.0.0` 当作访问地址。
- 提示端口占用时，先打开该地址，确认是否已启动游戏。若是其他程序占用，按[更换端口](setup.md#更换端口)操作。
- 修改服务器代码后需停止旧服务并重新启动；修改页面后刷新浏览器即可。

## Windows 双击启动窗口立即关闭

使用最新版 `启动游戏.cmd`。启动脚本使用 ASCII 内容和 Windows CRLF 换行，避免 `cmd.exe` 将中文或不兼容的换行误解析为命令；`.gitattributes` 会在 Git 检出时保留该格式。

启动失败时窗口会显示错误并等待按键。若提示缺少 Node.js、版本过旧或缺少 `server.cjs`，按窗口提示处理。也可先打开终端，进入项目目录执行 `.\启动游戏.cmd` 或 `npm start` 查看完整报错。正常运行期间需要保持服务窗口打开。

## 手机或其他设备打不开

按以下顺序检查：

1. 先确认电脑本机可以打开游戏。
2. 手机连接电脑所在路由器的 Wi-Fi，使用页脚显示的局域网 URL，包含 `http://` 和端口。手机中的 `127.0.0.1` 指向手机自己。
3. 确认使用的是电脑以太网或 Wi-Fi 地址，而非 VMware、VPN 或其他虚拟网卡地址。换网后刷新页面获取新地址。
4. 检查系统防火墙是否允许 Node.js 在可信的专用网络接收入站连接；Linux 也需允许实际使用的服务端口。无需关闭整个防火墙。
5. 检查路由器是否启用了访客网络或设备隔离；这些设置可能禁止设备互访。

手机建议横屏；牌桌宽于屏幕时，可横向滚动查看。

## 没有自动打开浏览器

直接访问终端打印的地址。Linux 启动脚本使用 `xdg-open`；没有桌面环境或系统未提供该命令时，服务器仍可继续运行。不要因此重复启动服务。

## 找不到上次进度

使用原浏览器和原地址，包括相同协议、IP、域名和端口。局域网 IP、`localhost` 和 `127.0.0.1` 的数据相互独立，也不会在手机和电脑之间同步。

确认浏览器允许本地存储，且没有清理站点数据。无痕窗口中的数据可能在窗口关闭后删除。开始新对局会替换旧进度，整场结束会清除存档。

刷新后回到上一个动作通常是正常行为：游戏只在完整动作结束后保存，未完成的动画或技能选择不作为存档。建议使用「暂离并保存」，等待保存完成再离开。

## 没有音效

先点击一次页面，再检查顶部音效开关、音量滑块、浏览器标签页静音状态及系统音量。确认项目中的 `sfx/` 目录完整；音量 0% 和静音设置会被浏览器保存。

## 卡图缺失或页面样式异常

保留完整项目目录，确认 `img/`、`svg/`、`sfx/` 与根目录脚本和样式均存在。使用 `npm start` 启动后强制刷新浏览器。Linux 文件名区分大小写，复制素材时不要修改文件名。
