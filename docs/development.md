# 开发与测试

[返回 README](../README.md)

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `index.html`、`theme.css`、`responsive.css`、`layout.css`、`style.css` | 界面、复古主题和牌桌布局 |
| `app.js` | 中文说明、界面状态与对局手记 |
| `progress.js` | 自动存档、暂离和读档 |
| `controls.js` | 滚轮、键盘换牌和音量 |
| `lan.js`、`network.cjs` | 局域网地址提示与网卡选择 |
| `gwent.js`、`abilities.js`、`factions.js` | 规则引擎、技能、阵营与电脑策略 |
| `cards.js`、`decks.js` | 卡牌数据和预设牌组 |
| `img/`、`sfx/`、`svg/` | 本地美术和音效 |
| `server.cjs`、`start.sh`、`启动游戏.cmd` | HTTP 服务与启动入口 |
| `tests/` | 规则、存档、音量与网络测试 |
| `docs/images/` | README 使用的界面截图 |

服务器无第三方依赖，默认监听 `0.0.0.0:5173`，端口可通过 `PORT` 设置。`/api/network-info` 返回当前网卡地址和访问 URL；静态路由只提供游戏资源，拒绝项目内部文件及隐藏路径。

## 回归测试

```sh
npm test
```

测试使用 Node.js 内置测试运行器，无需安装测试依赖。

| 测试文件 | 覆盖范围 |
| --- | --- |
| `tests/rules.test.cjs` | 牌组合法性、天气和加成顺序、英雄免疫、诱饵、烧灼、间谍、医生、召集、胜负及本地卡图 |
| `tests/progress.test.cjs` | 五个阵营的实际读档路径、牌库顺序、天气和号角、间谍归属、第三局复活、暂停边界、换牌 DOM 顺序、音量与文件名大小写 |
| `tests/network.test.cjs` | 以太网优先、Wi-Fi 回退、虚拟网卡过滤、实时端口、HTTP 资源和内部文件访问限制 |
| `tests/launcher.test.cjs` | Windows 启动脚本格式、中文和空格路径、缺少 Node.js、缺少服务文件、启动失败时保留窗口 |

存档测试通过 VM 和最小 DOM 环境调用实际引擎与恢复代码；网络测试会启动临时 HTTP 服务并发起本地请求。

启动脚本测试在 Windows 上调用真实 `cmd.exe`，在临时目录运行无后台服务的测试入口，确认等待按键后才退出；其他系统跳过 Windows 运行检查。修改 `.cmd` 后保留 ASCII 和 CRLF，`.sh` 保留 LF。

## 手动检查

- 换牌：滚轮、触控板和左右键切换，更换后逻辑顺序与显示顺序一致。
- 存档：换牌阶段刷新、实战暂离、返回首页和重启后继续；读档不重复触发技能。
- 音量：播放中调节、静音、刷新后恢复设置。
- 布局：桌面卡牌清晰，手机宽度下底部地址可读，牌桌可横向滚动。
- 网络：本机和实际以太网 IP 均可访问，页脚显示正确网卡及端口；其他设备另行验证路由器和防火墙。

当前开发环境为 Windows。Linux 启动脚本已做 Bash 语法检查，尚未进行 Linux 桌面环境实测。手机尺寸检查不等同于真实手机网络测试。
